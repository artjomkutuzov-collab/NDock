# Known limits

- First test target: Nikon Z8 C 3.10 and an Apple Silicon Mac running macOS 27 or later on the same local network.
- Installation on a second Mac is not yet verified.
- Start in Camera Control with a few JPEG or NEF files. HEIF import is not supported.
- Assistant is experimental. Its initial metadata scan may take time; recovery after a link drop still needs camera testing.
- There is no public installer yet.
